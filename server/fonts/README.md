# Schriften für Text-Einblendungen

Diese Schriften nutzt der Server (libass, `ass`-Filter mit `fontsdir`) zum
Einbrennen von Text. Das Frontend lädt dieselben Dateien für die Vorschau,
damit Vorschau und Ergebnis gleich aussehen.

| Roboto-Bold.ttf           | Roboto      | SIL OFL 1.1 (licenses/)        |
| Montserrat-ExtraBold.ttf  | Montserrat  | SIL OFL 1.1 (licenses/)        |
| BebasNeue-Regular.ttf     | Bebas Neue  | SIL OFL 1.1 (licenses/)        |
| Lora-Bold.ttf             | Lora        | SIL OFL 1.1 (licenses/)        |
| Pacifico-Regular.ttf      | Pacifico    | SIL OFL 1.1 (licenses/)        |

Quelle: Google Fonts (über die npm-Pakete `@expo-google-fonts/*`), unverändert.
